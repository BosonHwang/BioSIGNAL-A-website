B1

Framework

The general evaluation rules shared across every biosignal task. Bound directly to the Delphi consensus.

What is an evaluation task

A task is defined by a clinical decision and its adequacy criterion — not by an available label. Each task states the decision it supports.

Design & validation rules

Site/setting-shifted hidden test set for headline claims; declared data splits; disclosed input-quality filters applied consistently at inference.

Reporting rules

Error metric + clinical-adequacy metric together; abstention behaviour reported; failure severity by clinical consequence.

↑ Each rule traces to a consensus principle (CR-1, MT-1, RP-1 …) — the framework is the operational form of Part A.

B5

Metrics

Shared scoring logic across domains, with panel-specific extensions.

Standard performance

Task-appropriate accuracy: AUROC, sensitivity/specificity, MAE, event F1.

Clinical adequacy

Threshold-referenced: does the output support the clinical decision it claims to?

Failure severity

Errors weighted by clinical consequence, not average deviation.

Robustness

Performance retention under missing / noisy / dropped channels.

Coverage / abstention

Behaviour on OOD inputs; calibration of “I don't know”.

Panel-specific

Extensions a domain requires (e.g. per-lead amplitude fidelity for ECG).
