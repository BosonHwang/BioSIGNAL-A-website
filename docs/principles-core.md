## A · Task prioritisation (core)

| ID | Title |
|----|--------|
| TP-1 | Begin from a documented care gap |
| TP-2 | Bind the task to a defined clinical decision |
| TP-3 | Prefer tasks where failure cost is clinically describable |
| TP-4 | Do not let label availability alone justify priority |
| TP-5 | Require a path to multi-site / multi-device evaluation |
| TP-6 | Make equity measurable by design |
| TP-7 | Prefer tasks that change what models are rewarded for |

## B · Benchmark design (core)

| ID | Title |
|----|--------|
| BM-1 | Specify intended use, population, and setting |
| BM-2 | Define endpoints by the decision, not only by the label |
| BM-3 | Disclose the acquisition and processing chain |
| BM-4 | Test clinically grounded distribution shift |
| BM-5 | Report subgroup performance and calibration |
| BM-6 | Score clinical adequacy alongside error metrics |
| BM-7 | Require external validation for headline claims |
| BM-8 | Name the comparator and the analysis pipeline |
