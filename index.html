A clinically grounded evaluation network for biosignal AI

Decide the rules before building the leaderboard.

Biosignal AI is scored on what public corpora happen to label — not on the clinical decisions that matter. BioSIGNAL-AI is a consortium to agree which tasks deserve priority and how those tasks become clinically grounded benchmarks.

Register interest → Read draft principles

Why

When tasks are inherited from data, benchmarks track what has been measured — not what needs to be.

Foundation models amplify the mismatch: a generality claim is evidenced by the count of corpus-backed tasks, not by the clinical decisions a model would inform. Fixing that is a public good — shared principles first, platforms later.

01

Two questions, not a suite of datasets

Which clinical problems should be prioritised as benchmarking tasks? How should those tasks be translated into clinically grounded benchmarks?

02

Consensus before infrastructure

We publish candidate principles now, run a multidisciplinary Delphi next, then build a prioritised task portfolio, specification template, and a worked pilot — not a premature leaderboard.

Candidate principles · Draft v0.2

Shared core + ECG / EEG / PPG extensions.

Two families mirror the consortium’s questions. Everyone rates the shared core; modality experts also rate ECG, EEG, or PPG extensions. Other modalities come later. Not consensus yet.

Shared core · all experts
TP-1Draft

Begin from a documented care gap

Start from a stated clinical need — not from a public label set.

TP-2Draft

Bind the task to a defined clinical decision

State who acts, what decision, and in which setting.

TP-3Draft

Prefer tasks where failure cost is clinically describable

Name consequences of false negatives, false positives, and abstention.

TP-4Draft

Do not let label availability alone justify priority

Convenient labels are not sufficient grounds for the portfolio.

TP-5Draft

Require a path to multi-site / multi-device evaluation

Tasks must be evaluable beyond one acquisition regime.

TP-6Draft

Make equity measurable by design

Pre-specify material subgroups and how underperformance is detected.

TP-7Draft

Prefer tasks that change what models are rewarded for

Redirect optimisation toward clinically grounded endpoints.

ECG-specific · extends core
TP-ECG-1Draft

Lead set and device class are part of the task claim

12-lead, reduced-lead, patch, and wearable single-lead are different claims — no silent transfer.

TP-ECG-2Draft

Prefer tasks where morphology (not only rhythm) binds care

If the decision depends on localised morphology, say so in the brief.

TP-ECG-3Draft

Acuity and recording condition must match the claimed gap

Acute-care tasks cannot be prioritised solely on elective outpatient corpora.

EEG-specific · extends core
TP-EEG-1Draft

Montage, reference, and channel set define the decision context

“Seizure detection” does not transfer across montages and setups.

TP-EEG-2Draft

Prefer tasks that name the review / escalation decision

Who reviews alerts, under what workload, toward what escalation.

TP-EEG-3Draft

Artefact and noise regimes are part of prioritisation

Declare in-scope artefact conditions for the care setting.

PPG-specific · extends core
TP-PPG-1Draft

Wearable vs clinical PPG are different task families

Separate ambulatory optical use from bedside PPG, including motion and wear-time.

TP-PPG-2Draft

Prefer tasks where perfusion and skin-tone strata matter

Name systematic failure risk at prioritisation time, not only in post-hoc tables.

TP-PPG-3Draft

Prefer tasks bound to an actionable threshold or workflow

State the action informed — not only continuous metric estimation.

Shared core · all experts
BM-1Draft

Specify intended use, population, and setting

State the use claim, population, setting, device class — and what is out of scope.

BM-2Draft

Define endpoints by the decision, not only by the label

Corpus labels are starting points, not automatic endpoints.

BM-3Draft

Disclose the acquisition and processing chain

Device, placement, filtering, segmentation, quality gates — including at inference.

BM-4Draft

Test clinically grounded distribution shift

Headline claims need declared shifts (site, device, acuity, population).

BM-5Draft

Report subgroup performance and calibration

Pre-specified strata and threshold behaviour for the use claim.

BM-6Draft

Score clinical adequacy alongside error metrics

Pair conventional metrics with harm-aware / adequacy measures.

BM-7Draft

Require external validation for headline claims

Independent site and/or device regime for fitness claims.

BM-8Draft

Name the comparator and the analysis pipeline

Freeze a transparent scoring pipeline as shared infrastructure.

ECG-specific · extends core
BM-ECG-1Draft

Declare lead set, placement, and lead availability

State required leads and how missing / noisy leads are handled at train and test.

BM-ECG-2Draft

Preserve diagnostically important morphology in adequacy criteria

Morphology- or feature-level adequacy — not MAE / correlation alone.

BM-ECG-3Draft

Separate rhythm claims from morphology / reconstruction claims

A downstream rhythm check cannot substitute for morphology-critical use evaluation.

BM-ECG-4Draft

Score device- and acuity-shifted ECG explicitly

Put those shifts in the primary evaluation table when the claim extends beyond development regime.

EEG-specific · extends core
BM-EEG-1Draft

Fix and report montage, reference, and preprocessing

Lock montage/reference assumptions used for scoring.

BM-EEG-2Draft

Evaluate under clinically realistic artefact regimes

Include artefact / noise conditions of the intended monitoring setting.

BM-EEG-3Draft

Report operating points that respect review workload

Alert burden / PPV at thresholds relevant to human review.

BM-EEG-4Draft

Align with federated panel norms where they exist

Compose with specialised EEG frameworks without erasing their governance.

PPG-specific · extends core
BM-PPG-1Draft

Disclose optical hardware, site, and motion / wear-time gates

Report sensor, location, motion filtering, and quality thresholds at train and inference.

BM-PPG-2Draft

Require stratum reporting for skin tone and perfusion when material

Make stratum metrics part of the headline report for affected use claims.

BM-PPG-3Draft

Test motion and ambulatory shift as first-class conditions

Motion-rich evaluation is primary evidence for wearable claims.

BM-PPG-4Draft

Tie metrics to the decision threshold of the use claim

Report the operating point implied by the action — not only continuous error.
